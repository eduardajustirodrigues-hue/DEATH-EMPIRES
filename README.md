# Império Medieval

Protótipo inicial de um jogo medieval para celular, feito com HTML, CSS e JavaScript puro.

## O que já funciona

- Cidade principal
- Recursos
- Construções e evolução
- Produção automática de recursos
- Exército
- Treinamento de tropas
- Mapa inicial
- Batalha de treinamento
- Perfil
- Salvamento local no navegador
- Interface responsiva para celular
- PWA básico

## Como publicar no GitHub

1. Crie um repositório chamado `imperio-medieval`.
2. Envie todos os arquivos desta pasta para o repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde o GitHub Pages publicar.
