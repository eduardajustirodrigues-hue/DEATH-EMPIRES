# DEATH-EMPIRES — 3D V1

Primeiro núcleo 3D do projeto.

## Contém
- Mundo 3D WebGL
- Câmera orbital com rotação e zoom
- Terreno
- Florestas
- Castelo medieval procedural
- Muralhas e torres
- Bandeiras
- Quartel, fazenda, serraria e academia
- Soldados 3D simples patrulhando
- Fumaça e iluminação
- HUD de recursos
- Menu, missões, correio e aliança
- Interface mobile

## Publicação
O projeto pode ser hospedado no GitHub Pages. O Three.js é carregado pelo CDN jsDelivr, portanto o dispositivo precisa estar conectado à internet para carregar o motor 3D.
